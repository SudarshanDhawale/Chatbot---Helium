# Lanyard Assets

This folder should contain the following files for the Lanyard component to work:

## Required Files:

1. **card.glb** - The 3D model file for the ID card
2. **lanyard.png** - The texture image for the lanyard band

## Where to get these files:

You need to download these files from the original React Bits repository or create your own:

- Download from: https://github.com/react-bits/react-bits (look in the lanyard component assets)
- Or create your own card.glb file using a 3D modeling tool
- The lanyard.png can be any texture image you want for the band

## Editing the card:

You can edit your card.glb file in this online .glb editor and change the texture:
- https://modelviewer.dev/editor/

## Notes:

- The card.glb file should contain meshes named: 'card', 'clip', and 'clamp'
- The materials should include 'base' and 'metal'
- The lanyard.png is the texture for the lanyard's band and can be edited in any image editor

Prefers Reduced Motion Test

Current Motion Preference Status

Checking...

This test detects whether your system has "Reduce Motion" enabled.

Visual Test: Animated Box

This box should animate (slide and fade) continuously when motion is NOT reduced.

When "Reduce Motion" is enabled, the animation should be disabled or nearly instant.

Expected behavior:

  • Motion enabled: Box slides back and forth smoothly
  • Motion reduced: Box stays still or moves instantly

Interactive Test: Hover Effect

Hover over this button to test transition effects:

Expected behavior:

  • Motion enabled: Smooth color transition on hover
  • Motion reduced: Instant color change on hover

How to Test

To enable "Reduce Motion" on different systems:

macOS:

  1. Open System Settings (or System Preferences)
  2. Go to Accessibility → Display
  3. Enable "Reduce motion"
  4. Refresh this page

Windows 10/11:

  1. Open Settings
  2. Go to Accessibility → Visual effects
  3. Turn off "Animation effects"
  4. Refresh this page

Linux (GNOME):

  1. Open Settings
  2. Go to Accessibility → Seeing
  3. Enable "Reduce animation"
  4. Refresh this page

Browser DevTools (for testing):

  1. Open Chrome/Edge DevTools (F12)
  2. Press Ctrl+Shift+P (or Cmd+Shift+P on Mac)
  3. Type "Emulate CSS prefers-reduced-motion"
  4. Select "Emulate CSS prefers-reduced-motion: reduce"
  5. The page will update automatically

Test Results

Toggle the "Reduce Motion" setting and observe the changes:

  • Status indicator should update automatically
  • Animated box should stop animating when motion is reduced
  • Button hover effect should become instant when motion is reduced

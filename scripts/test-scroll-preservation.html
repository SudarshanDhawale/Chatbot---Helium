Task 6.2: Scroll Preservation Test

This test verifies that the SyntaxHighlighter is configured correctly to preserve scroll behavior with wrapLongLines={false} and proper PreTag configuration.

Test 1: Very Long Single Line
This test contains a single line of code that is extremely long (200+ characters).
Expected Behavior:
  • The line should NOT wrap to the next line
  • A horizontal scrollbar should appear
  • You should be able to scroll horizontally to see the entire line
  • The code should maintain its formatting

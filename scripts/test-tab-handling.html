Tab Character Handling Test

Test Objective: Verify that tab characters render consistently with 4-space width

Expected Behavior:

  • Each tab character should render as 4 spaces
  • Tabs should be consistent across all code blocks
  • Mixed tabs and spaces should align properly

Test 1: JavaScript with Tabs

JavaScript

	console.log("This line has 1 tab");
		console.log("This line has 2 tabs");
			console.log("This line has 3 tabs");
}

JavaScript
